# ShaftWizard ⚙️

Инженерное десктопное приложение для расчета, подбора подшипников и автоматической генерации 3D-моделей валов редукторов. 
Проект создан на стыке машиностроения и Python-разработки, чтобы избавить инженера от рутинных расчетов и кликов в САПР.

## ✨ Возможности
- **Расчет на прочность:** Автоматический расчет реакций опор, изгибающих моментов и минимального диаметра вала по III теории прочности.
- **Подбор подшипников:** Расчет эквивалентной динамической нагрузки и подбор подшипников качения по ГОСТ 8338-75 из встроенной JSON-базы.
- **Параметрическая 3D-генерация:** Ввод ступеней вала (диаметр и длина) и автоматическое создание 3D-модели (тела вращения) в формате `.FCStd` через интеграцию с FreeCAD.
- **Современный UI:** Темный интерфейс на базе `ttkbootstrap` (тема Catppuccin) с удобным добавлением ступеней.

## 🛠️ Технологии
- **Python 3.10+**
- **Tkinter + ttkbootstrap** (GUI)
- **FreeCAD API + CalculiX** (Автоматизация 3D и CAE-анализ)
- **Pytest** (Покрытие бизнес-логики тестами)
- **JSON** (База данных подшипников)

## 🚀 Запуск (Linux)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/engicode-dev/shaft-wizard.git
   cd shaft-wizard
   ```

2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. Убедитесь, что в системе установлен FreeCAD (для работы генератора 3D):
   ```bash
   sudo apt install freecad
   ```

4. Запустите приложение:
   ```bash
   python main.py
   ```

├── ui/                      # Графический интерфейс

│   └── app.py               # Главное окно, вкладки, таблица ступеней

    ├── __init__.py
    ├── test_mechanics.py    # Тесты расчетов
    └── test_bearings.py     # Тесты подбора
```

## 📝 Пример работы (Кейс)

В рамках разработки был выполнен полный инженерный кейс:
1. Ручной расчет вала в wxMaxima.
2. Построение эпюр изгибающих моментов.
3. CAE-анализ (FEM) в FreeCAD (CalculiX) для оценки концентраторов напряжений в шпоночных пазах.
4. Автоматизация генерации 3D-модели через Python.
